# Лабораторная работа №12 — Трёхстраничное SPA на Vue 3

### Выполнил: Студент

### Описание проекта:
Разработано одностраничное приложение (SPA) с использованием фреймворка Vue 3, Vue Router и менеджера состояний Pinia.

### Реализованный функционал:
1. **Главная страница (`/`)**: Содержит текстовую общую информацию на тему SPA архитектуры.
2. **Страница данных (`/data`)**: При загрузке страницы срабатывает экшен Pinia, отправляющий асинхронный GET-запрос к API `jsonplaceholder.typicode.com/users` и отрисовывающий список имен пользователей.
3. **Страница формы (`/form`)**: Содержит поля ввода, связанные двусторонним связыванием `v-model` с хранилищем. Данные упаковываются в объект и отправляются POST-запросом в JSON формате на имитационный сервер.

### Как запустить проект локально:
1. Установить зависимости: `npm install`
2. Запустить сервер для разработки: `npm run dev`
